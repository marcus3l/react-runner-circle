# Runner Circle — comunidade de corrida

Aplicação social para corredores compartilharem treinos e acompanharem publicações da comunidade. O projeto inclui telas de autenticação, feed, criação de posts e edição de perfil.

## Funcionalidades

- Cadastro, login e edição de perfil
- Feed de publicações sobre treinos
- Formulário para criar uma publicação
- Componentes reutilizáveis de interface e navegação

## Tecnologias

React, JavaScript, Vite, Tailwind CSS, Material UI, Apollo Client e GraphQL.

## Como executar

```bash
npm install
npm run dev
```

O Vite informa no terminal o endereço local da aplicação. O `package.json` também inclui comandos para iniciar os serviços de demonstração com JSON Server e JSON GraphQL Server.

## Contexto

Projeto educacional de React com foco em interface, formulários e integração com dados.
